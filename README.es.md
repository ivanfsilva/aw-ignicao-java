Este repositorio contiene los ejercicios y el proyecto práctico desarrollados durante la capacitación **Ignição Java**
de la plataforma 🍃 **AlgaWorks**.

El objetivo de este espacio es consolidar los fundamentos del lenguaje Java y el paradigma de Programación Orientada a
Objetos (POO), aplicando conceptos esenciales de sintaxis, modelado de clases, métodos, atributos y reglas de negocio a
través de una aplicación de consola.

---

## 🛠️ Tecnologías y Herramientas

- **Lenguaje:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA
- **Calidad de Código:** SonarLint / SonarQube _(análisis estático en el IDE)_
- **Control de Versiones:** Git & GitHub

## 🚀 Cómo Ejecutar el Proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/ivanfsilva/aw-ignicao-java.git
```

2. Abre IntelliJ IDEA (o tu IDE preferido) e importa la carpeta del proyecto.
3. Asegúrate de que el SDK configurado sea **Java 17** o superior.
4. Navega hasta la clase principal (ej: `com.aw.bank.app.Principal.java` o `Main.java`).
5. Ejecuta la clase e interactúa con el sistema a través de la consola del IDE.
