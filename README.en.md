This repository contains exercises and practical projects developed during the **Ignição Java** (Java Ignition) course
by 🍃 **AlgaWorks**.

The main goal of this project is to consolidate Java language fundamentals and Object-Oriented Programming (OOP)
principles, applying core concepts such as syntax, class modeling, methods, attributes, and business rules through a
console application.

---

## 🛠️ Technologies & Tools

- **Language:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA
- **Code Quality:** SonarLint / SonarQube _(IDE static analysis)_
- **Version Control:** Git & GitHub
- **Documentation:** Markdown _(complementary study/personal initiative)_

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/ivanfsilva/aw-ignicao-java.git
```

2. Open IntelliJ IDEA (or your preferred IDE) and import the project folder.
3. Ensure the project SDK is set to **Java 17** or higher.
4. Navigate to the main class (e.g., `com.aw.bank.app.Principal.java` or `Main.java`).
5. Run the class and interact with the application via the IDE console.
