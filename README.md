Este repositório contém os exercícios e o projeto prático desenvolvidos durante o treinamento **Ignição Java** da
plataforma 🍃 **AlgaWorks**.

O objetivo deste espaço é consolidar os fundamentos da linguagem Java e o paradigma de Orientação a Objetos (OO),
aplicando conceitos essenciais de sintaxe, modelagem de classes, métodos, atributos e regras de negócio através de uma
aplicação de console.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)

- **Qualidade de Código:** SonarLint / SonarQube _(análise estática na IDE)_

## 🚀 Como Executar o Projeto

1. Clone este repositório:

```bash
git clone https://github.com/ivanfsilva/aw-ignicao-java.git
```

2. Abra o IntelliJ IDEA (ou sua IDE de preferência) e importe a pasta do projeto.
3. Certifique-se de que o SDK configurado seja o **Java 17** ou superior.
4. Navegue até a classe principal do projeto (ex: `com.aw.bank.app.Principal.java` ou `Main.java`).
5. Execute a classe e interaja com o sistema através do console da IDE.
